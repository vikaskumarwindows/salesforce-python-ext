# Documentation Index

Welcome to the technical documentation for the **Python In-Browser Analytics (Pyodide WebAssembly)** Chrome Extension.

This project enables real CPython, NumPy, and Pandas to run 100% inside Google Chrome via WebAssembly without hosting any server or running native host processes.
